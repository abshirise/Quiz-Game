# 🧠 Quiz Master – Multiple Choice Quiz Game

## 📌 About
Quiz Master is an interactive multiple-choice quiz game built using HTML, CSS, and JavaScript. It features 10 questions, instant answer feedback, player and computer score tracking, a progress bar, and a final results screen.

## ✨ Features
- 10 multiple-choice questions.
- One question displayed at a time.
- Instant feedback for correct and incorrect answers.
- Player and computer score tracking.
- Dynamic progress bar.
- Final score and winner announcement.
- Restart game functionality.
- Responsive and modern user interface.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 📚 JavaScript Concepts Practiced
- Arrays and Array of Objects
- Objects
- If/Else Conditionals
- Functions
- DOM Manipulation
- Event Listeners
- Array Methods (`forEach()`)

## 🚀 How to Run
1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start playing and test your knowledge!
